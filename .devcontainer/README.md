# Dev Container

This Dev Container image is designed for developing ROS2 modules, with both C++ and Python stacks.
It also supports simulations with [Gazebo](https://gazebosim.org/).

## Info

- Base image: [ROS Docker Official Image](https://hub.docker.com/_/ros/)
- Baseline: `kilted-ros-base-noble`
